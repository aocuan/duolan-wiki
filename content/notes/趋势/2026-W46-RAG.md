# 2026 年第 46 周：RAG 与检索趋势

覆盖 2026-11-09 至 11-15。只保留当周形成的判断；论文和厂商数字都是作者自报，未经第三方复测。

## 这周的主线

- **agent 记忆的标准从「相似」变成「有用」。** 一周内出现多篇论文，主张记忆该学着写、按对决策有没有用来挑，而不是尽量多存再按相似度捞回。其中一篇逐条测试「有这条记忆和没有时 agent 的动作会不会变」，再训练小模型挑记忆，在受限记忆预算下明显好于 BM25。上个月的争论是朴素 RAG 够不够用，这周变成了怎么学会挑。
- **决策模型进入检索流程。** 大厂陆续发布不生成文字的决策模型，开源框架准备加入对应的模型类；论文开始测它给文档打相关性分是否校准，以及逐句挑证据。见 [[决策模型检索]]。
- **给 agent 用的搜索 API 在抢排行榜。** 几家都说自己第一，但都是自报。
- **RAG 架构选择趋于共识。** 普通 RAG、GraphRAG、Agentic RAG 各自解决不同问题，不是一级级升级：查单个事实用普通 RAG，查多层关系用 GraphRAG，要从多个来源动态找资料用 Agentic RAG。

## 升温与降温

升温：学习式记忆、决策模型做重排和挑证据、更便宜的稀疏与多向量检索（非对称稀疏模型、token pooling、多向量倒排索引）、不用检索器让 agent 直接用命令行或文件系统找东西（见 [[Agentic搜索]]）。

降温：没有足够硬的证据。只观察到 GraphRAG 这周基本只出现在科普和课程里，没有新的研究热点。

## 留给下周的问题

决策模型做重排有没有开源、可复现的结果；「按有用程度挑记忆」有没有第二篇跟进；搜索 API 榜单有没有第三方复测。
