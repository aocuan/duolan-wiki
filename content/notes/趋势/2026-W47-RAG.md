# 2026 年第 47 周：RAG 与检索趋势

覆盖 2026-11-16 至 11-22。延续 [[2026-W46-RAG]] 的主线，并回应了上周留下的问题。数字均为作者或厂商自报。

## 这周的主线

- **决策模型从论文走到可下载的权重和教程。** 多家发布决策模型，出现开放权重版本，也有人在公开博客里拿它当重排器做实验，还有人整理出决策模型在 agentic RAG 里能用的九个位置（从模型路由到证据挑选）。
- **「按有用程度挑记忆」出现可复现的跟进。** 有带代码的论文用决策模型给每条记忆估「对回答有用」的概率；大厂也发布了让模型自己改记忆读写规则的工作。反方证据同样出现：一些场景里最小记忆就够用。两边哪边证据更多，还要再看。
- **代码检索：grep 和 embedding 不是二选一。** 一套开源代码搜索方案把 grep 和语义加关键词混合索引一起用，再重排，成本只有大模型只用 grep 的约十分之一；另一篇论文用公平设置的 BM25 加上先让模型补写标识符，在 Python 测试集上追平了稠密检索。共同建议是两者一起用，代码库越大越需要索引补位。
- **搜索 API 开始按「每拿到一个正确答案花多少钱」比较，并且有了第三方实测。** 算 agent 成本时，要把搜索调用和读结果的 token 一起算。
- **重排不是越深越好。** 有研究发现把重排加深或拉宽，收益很快到顶。

## 升温与降温

升温：决策模型进检索、按有用程度挑记忆、代码检索的混合方案、搜索成本比较、更便宜的多向量检索（包括扩展到音频）。

降温观察：[[PageIndex]] 和无向量检索这周主要是旧文改写和推广帖；GraphRAG 唯一的硬货是建索引时不调用大模型的新方案，其他多是教程。有人指出 BEIR 已不适合当前的检索评测，并预告新基准。

## 留给下周的问题

开放决策模型有没有第三方复测；BEIR 的替代基准会不会发布；「记忆够用就好」和「学习式记忆」哪边证据更多。
