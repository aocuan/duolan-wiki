# 2026 年 11 月 GitHub 扫榜：agent 工具的走向

这份是 11 月 1 日到 26 日每日扫榜里稳定下来的判断，不是逐日榜单。星标数字截至 2026-11-26（太平洋时间），只作热度线索，不代表质量。

## 五条趋势

1. **调度多个编码 agent 的控制面持续最热。** [[t3code]] 整月都在月榜头部，说明「在电脑或手机上统一指挥 Claude Code、Codex 这类 agent」是刚需。派活和审批也开始产品化，例如 [[LoopForge]] 把沙箱、角色和人工审批关卡做成可复用流程。
2. **给 agent 的「手」：浏览器和桌面工具。** [[agent-browser]]（约 5.4 万星）、[[chrome-devtools-mcp]]（约 6.0 万星）、操作整个桌面的 agent-desktop 轮流上榜。共同做法是让 agent 用短命令一步步操作、每步只读很少的文本。
3. **记忆和上下文是另一条主线。** [[claude-mem]] 月增上万，总星超过 12 万；想把工具输出挡在上下文窗口外的 context-mode（约 3.5 万星）也很热，但它使用 Elastic License 2.0，属于源码可用而非 OSI 开源，用前看清许可证。更系统的分层见 [[Agent知识库项目地图]]。
4. **协议层开始稳定。** [[AG-UI]] 发布 1.0 冻结规范，agent 到前端的对接有了标准；Cursor、Anthropic 等也在推各自的插件规范和官方合集。
5. **Skills 从「越多越好」转向「审、管、评」。** 大合集还在涨，但新热点是给 skill 做安全扫描和打分。[NVIDIA/SkillSpector](https://github.com/NVIDIA/SkillSpector)（约 2.8 万星）扫 skill 里的漏洞和恶意模式。装第三方 skill 前先看内容，见 [[薄技能与重框架]]。

## 值得单独记一笔的新面孔

- [[auto-ontology]]：11 月初开源后连续几天领跑日榜，代表「给 agent 的语义层」。
- [[nod]]：n8n 出的自带电脑的个人 agent，11 月中旬进周榜。
- [[Plannotator]]：给 agent 的计划和改动做批注再回传，人机协作审阅层。

## 不要被带偏的

日榜里常有与 agent 无关的爆款（个人记账、股票分析、按用户名查社交账号、视频增强工具等），以及跟风的 skill 合集和越狱提示词合集。它们不进本知识库。
