# Maka

[Apache Maka](https://github.com/apache/maka)（孵化中）是本机编码 agent 工作台，强调把做过的事完整记下来。许可证是 Apache-2.0。星标 5,980，统计截至 2026-11-17（太平洋时间），仓库当天仍有推送。

## 开源范围

它按产品形态就没有自营云控制面：本机工作台，模型自己接。不是把云藏起来，是这一截本来就不在范围里。它是 Apache 孵化器项目，还不是毕业后的正式发行，评估生产可用性时要把孵化风险算进去。

## 和相邻项目的差别

- 对照 [[Memoh]]、[[Rakazo]]：那些是 agent 电脑或控制面；Maka 对标的是本机编码工作台。
- 对照 [[Lody]]：Lody 调度已有编码 CLI；Maka 自己就是编码 agent 工作台。
- 对照 [[Goose]]、[[OpenHands]]：同属编码 agent，但 Goose / OpenHands 的部署形态和云分层不同。
