# Omnigent

[Omnigent](https://github.com/omnigent-ai/omnigent) 是开源的 agent 框架和元 harness：编排 Claude Code、Codex、Cursor、Pi 等，强调换 harness 而不用重写，并加上策略、沙箱和跨设备协作。官网是 [omnigent.ai](https://omnigent.ai)。许可证是 Apache-2.0。星标 11,396，统计截至 2026-11-17（太平洋时间），仓库当天仍有推送。

## 开源范围

开源同步和共驾面相对完整，可以 fork 和自托管。它常被放进「同一 Session 多人协作」里看，和只做单人遥控的控制面不是同一需求。

## 和相邻项目的差别

- 对照 [[Lody]]：都涉及共享会话，但 Lody 的跨设备同步主要走官方云；Omnigent 把更多协作面放在开源仓库里。
- 对照 [[Buzz]]：Buzz 是团队房间；Omnigent 是 harness 编排加会话共驾。
