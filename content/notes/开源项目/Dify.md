# Dify

[Dify](https://github.com/langgenius/dify) 用来搭建 agent 工作流和检索流水线，并可在不同环境部署。官网是 [dify.ai](https://dify.ai)。星标 161,337，统计截至 2026-11-17（太平洋时间），仓库当天仍有推送。许可证是带附加条件的 Apache-2.0：把源码拿去运营多租户服务，或去掉前端标识，会另有限制。

它首先是编排平台，不是企业搜索产品。知识问答应先看 [[Onyx]]、[[WeKnora]] 或 [[RAGFlow]]。选型见 [[企业知识库开源选型]]。
