# agent-skills（addyosmani）

[addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) 把资深工程师的工作流程和质量关卡打包成编码 agent 的技能。它按开发生命周期提供 `/spec`、`/plan`、`/build`、`/test`、`/review`、`/ship` 等斜杠命令，每个命令自动激活对应技能。许可证 MIT，星标 120,668，截至 2026-11-26（太平洋时间）。

## 判断

它是「阶段门禁」路线的代表：每个阶段都有明确产出和检查。和 Matt Pocock 那种先把人问清楚、再按需加载的小技能链相比，它更完整也更重。两者思路不同，最好选一套，不要混着装。

取舍见 [[薄技能与重框架]]。入口：[[indexes/开源项目]]。
