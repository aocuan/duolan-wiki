# claude-obsidian

[claude-obsidian](https://github.com/AgriciDaniel/claude-obsidian) 把 Obsidian 和 Claude Code 组合成「自己整理的第二大脑」：把论文、文章、转写稿或笔记放进 `inbox/`，模型读完后写出带来源的双链笔记、索引和内容地图，还会检查死链、孤立页面和缺口。原始资料保持不动，所有内容都是本地 Markdown。许可证 MIT，星标 16,788，截至 2026-11-26（太平洋时间）。主仓最近一次推送是 2026-10-25，更新比年中慢。

## 判断

它是 [[LLM知识库]] 思路的完整实现。适合库的结构已经稳定、想把整理工作交给模型的时候；刚起步时，先自己定好目录和规则更稳。
