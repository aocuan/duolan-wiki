# Paperclip

[Paperclip](https://github.com/paperclipai/paperclip) 把自己写成工作中管理 agent 的开源应用。官网是 [paperclip.ing](https://paperclip.ing)。许可证是 MIT。星标 114,442，统计截至 2026-11-17（太平洋时间），仓库当天仍有推送。

## 开源范围

主仓按 MIT 开源，定位是组织里如何管一批 agent，而不是再做一个个人聊天助手。和早期一些同名、偏「组织架构式编排」的讨论可能不是同一条产品线，引用时以当前主仓为准。

## 和相邻项目的差别

- 对照 [[Buzz]]：Buzz 是房间；Paperclip 是工作场所里的 agent 管理。
- 对照 [[Multica]]：两者都偏团队派活和管理，许可证和附加条件要各看各的。
- 对照 [[Agent-Orchestrator]]：都在「计划、监督一队 agent 直到合并变更」，具体界面和许可不同。
