# Pi

[Pi](https://github.com/earendil-works/pi) 是一套 agent 工具箱：统一的模型接口、agent 循环、终端界面和编码命令行。许可证是 MIT。星标 122,453，统计截至 2026-11-17（太平洋时间）。仓库曾从旧组织迁过来，软件包名称也改过，引用时以当前仓库为准。

## 开源范围

它是底层循环和接口，不是完整的个人助手产品。[[Rakazo]] 等项目会依赖其中的循环和模型层，再自己写工具和产品界面。[[OpenClaw]] 一度内嵌过相关能力，后来把循环收进自己的代码。[[Lorca]] 则按相近设计另写实现。

看一个产品「是不是用了 Pi」，要核对依赖和说明，不能只看品类。入口：[[indexes/开源项目]]。
