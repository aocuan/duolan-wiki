# Hermes Agent

[Hermes Agent](https://github.com/NousResearch/hermes-agent) 是 Nous Research 的开源个人助手。官网是 [hermes-agent.nousresearch.com](https://hermes-agent.nousresearch.com)。许可证是 MIT。星标 264,044，统计截至 2026-11-17（太平洋时间），仓库当天仍有推送。

## 开源范围

主仓库按可自部署的助手来开源。官方另有付费托管（Hermes Cloud 一类）：每个 agent 一个容器、按天计费，模型费用另算。助手本身仍可完全自托管；托管层不要默认看成已经开源。

## 和相邻项目的差别

- 对照 [[OpenClaw]]：两者经常被放在同一层比较，都是可自托管的个人助手 / 网关。
- 对照 [[nanobot]]：同一层里更轻的一条路线。
- 对照 [[Pi]]：Hermes 是完整产品；Pi 更常作为别的产品使用的循环和模型层。
