# nanobot

[nanobot](https://github.com/HKUDS/nanobot) 定位是轻量的开源个人 agent。官网是 [nanobot.wiki](https://nanobot.wiki)。许可证是 MIT。星标 50,146，统计截至 2026-11-17（太平洋时间），仓库当天仍有推送。

## 开源范围

它可以自部署，属于个人助手 / 网关这一层，不是 agent 机房。内核是项目自己写的循环，而不是直接复用某一家编码 CLI。

## 和相邻项目的差别

- 对照 [[OpenClaw]]、[[Hermes-Agent]]：同属个人助手底座，体量和生态不同，比较时盯渠道、隔离和是否自托管，而不是只看星标。
- 对照 [[Memoh]]：nanobot 不是「每 agent 一台电脑」。
