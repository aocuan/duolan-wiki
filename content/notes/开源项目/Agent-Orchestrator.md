# Agent Orchestrator

[Agent Orchestrator](https://github.com/OrchestratorInc/agent-orchestrator) 用来规划、运行和监督一批 agent，从任务一直跟到变更合并。支持多种编码 agent，并提供桌面和移动应用。官网是 [orchestrator.inc](https://orchestrator.inc)。许可证是 Apache-2.0。星标 14,834，统计截至 2026-11-17（太平洋时间），仓库当天仍有推送。

它和 [[Herdr]]、[[Multica]] 一样属于调度 / 监督层，不是 [[OpenClaw]] 那种个人网关，也不是 [[Buzz]] 那种房间。入口：[[indexes/开源项目]]。
