# Memory Tax

它和 [[RAW-RAG]] 一起，把讨论从「要不要做更聪明的记忆」拉回「先衡量净收益」。对工程上的含义见 [[RAG与检索手段]] 和 [[Agent记忆与聊天记录工具]]。
